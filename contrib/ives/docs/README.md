# IVèS README FOR ASTERISK

Hello,

At IVèS, we have decided to start a big work on Asterisk 18.12.1 for our needs.
The same way we did in the past, we will try to contribute to Asterisk upstream repository (as much as possible).

Our main objective is to use Asterisk 18 on AlmaLinux 8+.
We will not support any other Linux distribution, don't even waste time to ask for it.

## Docs folder

In this folder, you will find all documentation to work with this GitHub repository.
I will try to explain everything to allow anyone (or a new employee at IvèS) to work on our fork.

## Patches folder

In this folder, you will find all patches and files we apply to the original source code.
It will be our work.

* An official patch name (from Asterisk/Digium/Sangoma) starts with offi_
* A community patch name (from Fedora/EPEL/CentOS/etc.) starts with commu_
* An IVèS patch starts with ives_

## Scripts folder

In this folder, you will find all scripts and files we have created to ease the installation step, compile process, build rpm, etc.
Some scripts will be private, and will be pushed in our internal GitLab instance. These scripts contain confidential data.
